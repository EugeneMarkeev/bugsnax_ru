Неофициальная частичная озвучка Qwen3-TTS: **2469 голосовых фрагментов,
14 постоянных голосов персонажей**. Начальный набор — 723 фрагмента,
продолжение — ещё 1746. Неозвученные диалоги и песни остаются в оригинале.

## Установка

1. [Скачайте архив озвучки](https://github.com/EugeneMarkeev/bugsnax_ru/releases/latest/download/Bugsnax-Russian-Voice-v0.1.0.zip) и распакуйте.
   Архивы **Source code** содержат только установщик, без озвучки.
2. Закройте Bugsnax.
3. Windows: дважды нажмите **Install.cmd**. Mac: **Install.command**.
4. Запустите игру обычным способом через Steam. Для русского интерфейса и
   субтитров выберите русский язык в свойствах игры в Steam.

Python, Qwen, Git и отдельная видеокарта для установки и игры не нужны.
Установщик сам ищет игру в библиотеках Steam. Если не найдёт — предложит
выбрать папку: Steam → Bugsnax → Управление → Просмотреть локальные файлы.
Выберите папку Bugsnax, приложение Bugsnax.app или папку звуковых банков.

macOS пока **экспериментальная**: установщик подготовлен, но воспроизведение
на настоящем Mac ещё не проверялось. Он применит мод только при совпадении
контрольных сумм оригинальных банков; несовместимые файлы не перезаписывает.
Внутри `.app` поддерживается путь `Contents/Resources/Content/Audio/Build/Desktop`.
Если звук хранится иначе, можно выбрать сам каталог `Desktop`.

Если Mac не разрешает запуск `.command`, откройте Terminal, введите `bash `,
перетащите Install.command в окно и нажмите Enter. Не нужно отключать защиту
macOS. Установка выполняется с правами текущего пользователя, без `sudo`.

## Удаление и обновления

Запустите **Uninstall.cmd** или **Uninstall.command**. Восстановятся сохранённые
оригинальные банки. Резервная копия остаётся в папке звуков игры:
`.bugsnax-russian-voice/backup`. Не удаляйте её до удаления мода.

Если озвучка была установлена другим способом, наш установщик может распознать
её, но у него не будет собственных оригинальных резервных копий. В таком случае
для удаления используйте прежний установщик или проверку целостности в Steam.

Обновление игры или проверка целостности Steam может вернуть английскую озвучку.
Установите мод повторно, если версия банков всё ещё поддерживается. При сообщении
о несовместимости нужен обновлённый релиз мода. Мод конфликтует с другими заменами
этих же звуковых банков. Сохранения игры установщик не изменяет.

Для распакованного релиза нужно около 1.81 GiB; установщик временно создаёт
копии изменяемых файлов. Желательно иметь 5 GiB свободного места на диске игры.
Перед заменой проверяются все входные файлы, затем создаются резервные копии
и временные файлы. При ошибке замены выполняется откат изменённых банков.

## Для разработчика

В Git хранятся установщики, манифест контрольных сумм и документация. Большие
готовые банки находятся в release-архиве, не в истории Git. Папка `payload/`
исключена через `.gitignore`; веса моделей и оригинальные резервные копии
в проект не входят. Этот пакет использует готовые заменяемые банки; локальной
пересборки банков из отдельных WAV при установке здесь нет.

Сборка архива из проверенного набора:

```text
python tools/build_release.py --source /path/to/campaign
```

Проверки установщика на временных файлах:

```text
python -m unittest discover -s tests -v
```

Проверка совместимости без изменения установленной игры:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/windows.ps1 -Action Check
```

```sh
bash scripts/macos.sh check
```

Можно задать путь вручную: Windows `-GamePath "..."`; Mac — второй аргумент
после `install`, `uninstall` или `check`.

Для публикации создайте GitHub-репозиторий, отправьте код, создайте релиз
`v0.1.0`, прикрепите ZIP из `dist/` и файл `.sha256`. Пользователю нужна кнопка
скачивания релиза, а не `git clone`. Поддержка Steam Workshop для Bugsnax
не заявлена: этот пакет распространяется отдельно от Steam.

Подробное описание закреплённых голосов: [docs/voices.txt](docs/voices.txt).
Автоматические проверки озвучки: распознавание исходных и ускоренных записей,
проверка PCM и контрольных сумм, запуск событий через штатный FMOD игры на Windows.
Полного интерактивного прохождения и проверки воспроизведения на Mac не было.
