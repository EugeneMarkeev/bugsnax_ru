# Русская озвучка Bugsnax — v0.1.0

**Не устанавливайте этот пакет: обнаружена ошибка упаковки банков, вызывающая
писк диалогов. Исправление выпускается в v0.1.2. Голоса пересоздавать не нужно.**

Скачайте **Bugsnax-Russian-Voice-v0.1.0.zip** ниже и распакуйте архив.
Архивы **Source code** не содержат звуковых файлов.

Закройте игру и запустите:

- **Windows:** `Install.cmd`.
- **macOS:** `Install.command`. Если файл не открывается, в Terminal введите
  `bash `, перетащите файл в окно и нажмите Enter.

Игра определяется автоматически. Затем запускайте Bugsnax через Steam.
Для русского интерфейса и субтитров выберите русский язык в свойствах игры.
Python, Git, Qwen и отдельная видеокарта не нужны.

В наборе **2469 голосовых фрагментов и 14 постоянных голосов**. Начальный набор
содержит 723 фрагмента; продолжение добавляет 1746. Озвучка частичная:
оставшиеся диалоги и песни звучат в оригинале.

Windows: звуковые банки проверены через штатный FMOD игры. Установщики проходят
тесты на Windows и macOS в GitHub Actions. Воспроизведение самой игры на Mac
ещё не проверялось, поэтому поддержка macOS остаётся экспериментальной.
При несовпадении исходных банков установка откажется от замены файлов.

Для удаления запустите `Uninstall.cmd` или `Uninstall.command`.
Не удаляйте резервные копии из `.bugsnax-russian-voice/backup` в папке звуков игры.
Проверка целостности Steam может вернуть оригинальную озвучку.

Размер ZIP: около **1,3 ГБ**. После распаковки — около **1,81 GiB**;
желательно иметь ещё 5 GiB свободного места на диске игры для установки.

Файл `.sha256` содержит контрольную сумму архива.
