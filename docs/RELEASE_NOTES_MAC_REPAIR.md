# Маленькое исправление писка диалогов на Mac

Для русской озвучки из v0.1.0 или v0.1.1:

1. Скачайте **Bugsnax-Mac-Audio-Repair-v0.1.2.zip** ниже и распакуйте.
2. Закройте Bugsnax.
3. Запустите **Repair.command**. Затем откройте игру через Steam.

Заново скачивать 1,3 ГБ звуков не нужно. Исправление пересобирает установленные
банки локально и сверяет все итоговые SHA-256. Оригинальные резервные копии
сохраняются; при ошибке замены выполняется откат. Удаление озвучки:
**Uninstall.command**.

Если Mac блокирует запуск, откройте Terminal, введите `bash `, перетащите
**Repair.command** в окно и нажмите Enter. Защиту macOS отключать не нужно.
Если оригинальные резервные копии отсутствуют, восстановите файлы через
проверку целостности Steam и используйте полный установщик нового релиза.

Причина писка — ошибочное поле каналов и выравнивание смещений в FSB5.
Исправление проверено на всех 16 настоящих банках: результат побайтово
совпадает с полной пересборкой. Все 3993 записи правильно декодируются FMOD
Windows, речь с выхода микшера распознаётся нормально. Само воспроизведение
исправленного пакета на настоящем Mac ещё требует проверки.
