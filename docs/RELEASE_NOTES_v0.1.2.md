# Исправление писка и искажений диалогов

**Для уже установленной озвучки на Mac скачайте маленький
`Bugsnax-Mac-Audio-Repair-v0.1.2.zip`, распакуйте, закройте игру и запустите
`Repair.command`. Повторно скачивать 1,3 ГБ звуков не нужно.** Исправление
работает локально и проверяет итоговые контрольные суммы всех банков.
Резервные копии оригинальной озвучки сохраняются.

В предыдущих пакетах найдена ошибка упаковки FSB5: неверная ширина поля
каналов и выравнивание смещений. Часть монофонической речи движок читал как
шестиканальный звук. Ошибка воспроизведена через FMOD Windows после сообщения
о писке на Intel MacBook Pro 2019. Исправлены банки, голоса не генерировались заново.

**Скачайте `Bugsnax-Installer-v0.1.2.zip`, распакуйте в новую папку, закройте
игру и запустите `Install.command` на Mac или `Install.cmd` на Windows.**
Установщик скачает исправленный `Bugsnax-Sound-Pack-v0.1.1.zip` (~1,3 ГБ).
Предыдущую установленную озвучку он обновит, сохранив оригинальные резервные копии.
Архив звуков v0.1.0 использовать нельзя.

Удаление: `Uninstall.command` / `Uninstall.cmd`, без интернета.
Если оригинальная резервная копия отсутствует, сначала восстановите файлы
через проверку целостности Steam, затем установите новый пакет.

Новая проверка сравнивает PCM каждой записи после декодирования штатным FMOD
с упакованными данными. Дополнительно проверяется речь с выхода микшера.
Это проверка Windows-движка; повторный тест исправленного пакета на настоящем
Mac ещё нужен, поддержка macOS остаётся экспериментальной.

Озвучка частичная: 2469 фрагментов, 14 постоянных голосов; остальные диалоги
и песни остаются в оригинале. Python, Git и Qwen пользователю не нужны.
