# Русская озвучка Bugsnax — отдельный установщик и пакет звуков

**Не устанавливайте этот пакет: обнаружена ошибка упаковки банков, вызывающая
писк диалогов. Исправление выпускается в v0.1.2. Голоса пересоздавать не нужно.**

**Скачайте только `Bugsnax-Installer-v0.1.1.zip`** — это маленький установщик.
Распакуйте его, закройте игру и запустите `Install.cmd` на Windows или
`Install.command` на Mac. Пакет озвучки он скачает и распакует сам.
После обрыва соединения запустите установку снова для продолжения скачивания.

Для установки без интернета скачайте также `Bugsnax-Sound-Pack-v0.1.0.zip`
и положите его рядом с файлами установщика либо в родительскую папку.
Звуковой ZIP самостоятельно распаковывать не нужно.

В пакете те же **2469 фрагментов и 14 постоянных голосов**, что в v0.1.0.
Голоса не пересоздавались. Озвучка остаётся частичной: остальные диалоги
и песни звучат в оригинале.

Python, Git, Qwen и отдельная видеокарта пользователю не нужны.
Удаление: `Uninstall.cmd` / `Uninstall.command`, без интернета.

Windows: банки проверены через FMOD игры. Установщики проходят тесты на
Windows и macOS; воспроизведение самой игры на Mac пока не проверено,
поэтому поддержка macOS остаётся экспериментальной.

`SHA256SUMS-v0.1.1.txt` содержит контрольные суммы обоих архивов.

[Полная инструкция](https://github.com/EugeneMarkeev/bugsnax_ru#установка)
