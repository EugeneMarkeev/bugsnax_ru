# Изменения

## v0.2.0

- 3545 голосовых фрагментов и 15 постоянных голосов, включая отдельный голос Сладколапа.
- Завершён план сюжетных диалогов и добавлены разговорные записи без субтитров, включая DLC.
- Исправлены ошибочные привязки голосов и адаптированы реплики под исходные тайминги.
- Обновление с прежних пакетов, резервные копии, проверка SHA-256 и откат при ошибке.
- Песни, неречевые звуки и голоса существ сохранены в оригинале.
- Побайтовая проверка PCM через FMOD игры, проверка событий и записи микшера.
- Установщики проверены на Windows, Intel macOS и Apple Silicon macOS. Нативное воспроизведение на Mac и полное прохождение пока не проверены.

Скачайте Bugsnax-Installer-v0.2.0.zip. Он скачает звуковой пакет автоматически.
Для установки без сети положите Bugsnax-Sound-Pack-v0.2.0.zip рядом с установщиком.


## v0.1.2

- Исправлены звуковые банки: двухбитное поле каналов FSB5 и выравнивание
  смещений на 32 байта. Раньше часть монофонической речи читалась как 6 каналов.
- Новая проверка: декодирование всех упакованных записей через FMOD игры
  с побайтовым сравнением PCM, а также запись выхода микшера для проверки речи.
- Обновление старого пакета с сохранением резервных копий оригиналов.
- Пакет звуков теперь v0.1.1; состав реплик и голоса не изменены.
- Воспроизведение исправленного пакета на Mac требует повторного теста.

## v0.1.1

- Маленький установщик и отдельный звуковой пакет; сами голоса не изменены.
- Автоматическое скачивание звуков с GitHub, проверка SHA-256 и возобновление
  прерванного скачивания. Пакет можно скачать отдельно для установки без сети.
- Удаление работает без пакета звуков и подключения к интернету.

## v0.1.0

- 2469 русских голосовых фрагментов в 2466 событиях игры, 14 закреплённых голосов.
- Начальный набор: 723 фрагмента. Продолжение: 1746 фрагментов.
- Установка и удаление одним запуском для Windows и экспериментально для macOS.
- Автоматическое определение Steam-библиотек, проверка контрольных сумм,
  резервные копии и откат при ошибке замены файлов.
- 19 локальных проверок установщиков: Windows и Bash в WSL. CI проверяет
  временные файлы на Windows и macOS; это не проверка воспроизведения игры.
- Оставшиеся диалоги и песни сохраняются в оригинале.
- Воспроизведение проверено через штатный FMOD Windows-версии; полноценного
  прохождения и проверки воспроизведения на Mac ещё не было.
